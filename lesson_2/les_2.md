# Практическое занятие №6. Основы

## 1. Переменные, типы, вывод, f-строки

Python — динамически типизированный язык: тип определяется значением, а не объявлением.

```python
x = 10          # int
x = "десять"    # теперь str — это нормально
```

Основные типы:

| Тип | Пример | Особенность |
|---|---|---|
| `int` | `5` | целые числа |
| `float` | `3.14` | дробные |
| `str` | `"привет"` | строки, неизменяемые |
| `bool` | `True` / `False` | логический |
| `list` | `[1, 2, 3]` | изменяемый, упорядоченный |
| `tuple` | `(1, 2, 3)` | неизменяемый |
| `dict` | `{"a": 1}` | ключ-значение |
| `set` | `{1, 2, 3}` | уникальные элементы |

Проверка и приведение типов:

```python
type(5)              # <class 'int'>
isinstance(5, int)   # True

int("5")      # 5
str(5)        # "5"
float("2.5")  # 2.5
```

**f-строки** — основной способ форматирования:

```python
name = "Анна"
age = 20
print(f"Меня зовут {name}, мне {age} лет")
print(f"Через год будет {age + 1}")
```

Внутри `{}` можно писать любые выражения.

`print()` принимает параметры:

```python
print("a", "b", sep="-", end="!\n")   # a-b!
```

`input()` всегда возвращает **строку** — тип приводите явно.

## 2. Управляющие конструкции (if / for / while)

### Условия

```python
if x > 10:
    print("больше 10")
elif x == 10:
    print("равно 10")
else:
    print("меньше 10")
```

Тернарный оператор:

```python
status = "взрослый" if age >= 18 else "ребёнок"
```

Отступы — часть синтаксиса, стандарт — 4 пробела.

### Циклы

```python
for i in range(5):         # 0,1,2,3,4
for i in range(1, 6):      # 1..5
for i in range(0, 10, 2):  # 0,2,4,6,8
```

```python
i = 0
while i < 5:
    print(i)
    i += 1
```

Управление циклом:

```python
continue   # пропустить итерацию
break      # выйти из цикла
pass       # заглушка
```

## 3. Коллекции (list, dict, set, tuple)

### list — изменяемый, упорядоченный

```python
nums = [3, 1, 4, 1, 5]

nums.append(9)        # добавить в конец
nums.extend([2, 6])   # добавить несколько
nums.pop()            # удалить последний
nums.sort()           # сортировка на месте
sorted(nums)          # новый отсортированный список
nums[0]               # первый элемент
nums[-1]              # последний
nums[1:3]             # срез: элементы с индексами 1, 2
len(nums)             # длина
```

Важно: `a = b` копирует **ссылку**, а не список.

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)   # [1, 2, 3, 4] — изменился и a
```

Копия: `b = a[:]` или `b = a.copy()`.

### dict — ключ-значение

```python
person = {"name": "Анна", "age": 20}

person["city"] = "Москва"
person.get("age")            # 20
person.get("salary", 0)      # 0, если ключа нет
person.keys()                # ключи
person.values()              # значения
person.items()               # пары (ключ, значение)
```

`person["salary"]` при отсутствии ключа даст `KeyError` — используйте `.get()`.

### set — уникальные элементы

```python
s = {1, 2, 3, 3, 2}
print(s)   # {1, 2, 3}

a & b   # пересечение
a | b   # объединение
a - b   # разность
```

### tuple — неизменяемый

```python
point = (10, 20)
x, y = point   # распаковка
```

## 4. Строки и их методы

Строки **неизменяемы** — все методы возвращают новую строку.

```python
s.lower()               # "  hello, world  "

"abc".endswith("c")     # True

```

```python
s = "python"
s[0]      # 'p'
s[-1]     # 'n'
s[1:4]    # 'yth'
s[::-1]   # 'nohtyp' — разворот
```

Склейка:

```python
"-".join(["a", "b", "c"])   # "a-b-c"
```

## 5. Функции

### Объявление

```python
def greet(name):
    """Возвращает приветствие."""
    return f"Привет, {name}!"
```

- `return` возвращает значение и **завершает** функцию.
- Без `return` функция возвращает `None`.

### Аргументы

```python
def power(x, exp=2):
    return x ** exp

power(3)      # 9
power(3, 3)   # 27
```

**Ловушка:** не используйте изменяемые объекты как значения по умолчанию.

```python
def bad(x=[]):     # ПЛОХО
    x.append(1)
    return x

bad()   # [1]
bad()   # [1, 1] — неожиданно
```

Правильно:

```python
def good(x=None):
    if x is None:
        x = []
    x.append(1)
    return x
```

`*args` и `**kwargs`:

```python
def sum_all(*args):
    return sum(args)

sum_all(1, 2, 3)   # 6
```

### Аннотации типов

Подсказки помогают читать код и работают в IDE.

```python
def greet(name: str) -> str:
    return f"Привет, {name}!"

def average(marks: list[int]) -> float:
    return sum(marks) / len(marks)
```

### Docstring

Краткое описание функции — первая строка внутри тела.

```python
def add(a, b):
    """Возвращает сумму двух чисел."""
    return a + b

help(add)   # покажет docstring
```

### lambda

Короткая анонимная функция, обычно для передачи в другую функцию.

```python
square = lambda x: x ** 2
sorted(nums, key=lambda x: -x)
```

### Область видимости

Переменные внутри функции — локальные. Снаружи не видны.

```python
x = 10

def f():
    x = 5      # локальная x, не глобальная
    print(x)

f()      # 5
print(x) # 10
```

Для изменения глобальной — `global` (использовать не рекомендуется):

```python
count = 0

def inc():
    global count
    count += 1
```

### Функция как объект

Функции можно передавать и хранить в переменных.

```python
def apply(func, x):
    return func(x)

apply(lambda x: x + 1, 5)   # 6
```

## 6. Генераторы списков (list comprehension)

Компактная замена циклу для создания коллекций.

```python
squares = [x ** 2 for x in range(10)]
evens = [x for x in nums if x % 2 == 0]
words = [w.lower() for w in text.split()]

# словарь
lengths = {word: len(word) for word in words}

# множество
unique_lens = {len(w) for w in words}
```

Эквивалент:

```python
squares = []
for x in range(10):
    squares.append(x ** 2)
```

Вложенные условия:

```python
result = [x for x in nums if x > 0 if x % 2 == 0]
```

## 7. Встроенные функции

```python
len(nums)           # длина
sum(nums)           # сумма
min(nums), max(nums)
abs(-5)             # 5
round(3.14159, 2)   # 3.14
sorted(nums)        # новый отсортированный список
reversed(nums)      # обратный итератор
```

`enumerate` — индекс и значение:

```python
for i, val in enumerate(nums):
```

`zip` — параллельный обход:

```python
for a, b in zip(list1, list2):
    print(a, b)
```

`any` / `all`:

```python
any(x > 10 for x in nums)   # True, если хотя бы один > 10
all(x > 0 for x in nums)    # True, если все > 0
```

`map` / `filter` (кратко; comprehension обычно читаемее):

```python
list(map(str, nums))
list(filter(lambda x: x > 0, nums))
```

## 8. Обработка исключений (try/except)

Без этого код падает на первом же `int(input())` от пользователя.

```python
try:
    x = int(input("Введите число: "))
except ValueError:
    print("Это не число")
finally:
    print("Конец")
```

Несколько типов:

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("Деление на ноль")
except (ValueError, TypeError) as e:
    print(f"Ошибка: {e}")
```

`else` — если исключения не было:

```python
try:
    x = int(input())
except ValueError:
    print("Не число")
else:
    print(f"Всё хорошо, x = {x}")
```

Не ловите всё подряд через `except Exception` без причины — так теряются ошибки.

## 9. Файлы и with

Чтение:

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
```

Построчно:

```python
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

Запись:

```python
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("Привет\n")
```

Режимы:

| Режим | Значение |
|---|---|
| `"r"` | чтение (по умолчанию) |
| `"w"` | запись, файл перезаписывается |
| `"a"` | добавление в конец |
| `"rb"` / `"wb"` | бинарный режим |

`with` — менеджер контекста, сам закрывает файл даже при ошибке.

## 10. Импорт модулей, `__main__`

```python
import math
print(math.sqrt(16))   # 4.0

from random import randint
print(randint(1, 6))

import numpy as np
```

Разница:

- `import math` — доступ через `math.sqrt`.
- `from math import sqrt` — сразу `sqrt`.
- `import numpy as np` — псевдоним.

Свои модули: файл `utils.py` рядом со скриптом.

```python
from utils import my_function
```

Точка входа — `if __name__ == "__main__":`:

```python
def main():
    print("Программа запущена")

if __name__ == "__main__":
    main()
```

Этот блок выполняется только если файл запущен напрямую, а не импортирован.

# Самая длинная подстрока без повторяющихся символов

## Условие

Дана строка `s`. Найдите длину самой длинной подстроки без повторяющихся символов.

## Примеры

### Пример 1

**Входные данные:**

```text
s = "abcabcbb"
```

**Выходные данные:**

```text
3
```

**Пояснение:** Ответ — `"abc"`, длина 3. Обратите внимание: `"bca"` и `"cab"` — тоже правильные ответы.

### Пример 2

**Входные данные:**

```text
s = "bbbbb"
```

**Выходные данные:**

```text
1
```

**Пояснение:** Ответ — `"b"`, длина 1.

### Пример 3

**Входные данные:**

```text
s = "pwwkew"
```

**Выходные данные:**

```text
3
```

**Пояснение:** Ответ — `"wke"`, длина 3.

Обратите внимание: ответ должен быть именно подстрокой. Строка `"pwke"` является подпоследовательностью, а не подстрокой, поэтому она не подходит.

## Ограничения

- `0 <= s.length <= 5 * 10^4`
- `s` состоит из английских букв, цифр, символов и пробелов.
